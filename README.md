# HV — Advanced HTML Viewer

ملف تجريبي يضيف واجهة متقدمة لمعاينة وتحرير ملفات HTML محليًا داخل المتصفح.

ميزات النسخة الأولى:
- محرر كود (Ace) مع تلوين ولفّ النص.
- معاينة في iframe (srcdoc) مع خيارات: تشغيل JS، تعقيم (DOMPurify)، RTL.
- تنسيق HTML (js-beautify)، تصغير، تحميل، نسخ وملء شاشة.
- محاكاة أبعاد الأجهزة وميزة التحديث التلقائي.

تشغيل محليًا:

1. تسطيب:

   npm install

2. تشغيل التطوير:

   npm run dev

ملاحظة: هذه نسخة أولية. أقدر أضيف ميزات أقوى مثل:
- محرر أكثر متقدّم (Monaco أو CodeMirror 6) مع اكتمال تلقائي.
- فحص a11y (axe) وHTML validator.
- دعم فتح ملفات محلية بالسحب والإفلات واستعراض التاريخ.
- حفظ/استرجاع جلسات في localStorage.

لو تحب أطبّق هذه التعديلات مباشرة على الريبو وأفتح PR في فرع `feature/advanced-html-viewer`، أقدر أكمّل وأضيف المزيد (Monaco، i18n، اختبارات CI...).
