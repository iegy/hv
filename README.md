# 🌐 HTML Viewer

أداة ويب حديثة وسهلة الاستخدام لعرض ومعاينة ملفات HTML مباشرة في المتصفح.

## ✨ المميزات

- 📝 **محرر HTML متقدم** - حقل نص مريح للكتابة وتحرير كود HTML
- 👁️ **معاينة فورية** - شاهد التغييرات مباشرة أثناء الكتابة
- 💾 **حفظ تلقائي** - تُحفظ المحتويات تلقائياً في متصفحك
- ⬇️ **تحميل الملفات** - حمّل ملفات HTML موجودة وعدّلها
- 📤 **تنزيل الملفات** - احفظ عملك كملف HTML
- 📱 **متجاوب** - يعمل بشكل مثالي على جميع الأجهزة
- 🎨 **تصميم عصري** - واجهة مستخدم جميلة وحديثة

## 🚀 البدء السريع

### الاستخدام المباشر
1. افتح [HTML Viewer](https://iegy.github.io/hv)
2. ألصق أو اكتب كود HTML في المحرر
3. شاهد المعاينة الفورية على اليسار

### التحميل المحلي
```bash
git clone https://github.com/iegy/hv.git
cd hv
# افتح index.html في متصفحك
```

## 🎯 كيفية الاستخدام

### إدراج كود HTML جديد
1. اكتب أو الصق كود HTML في محرر النصوص
2. شاهد المعاينة تتحدث تلقائياً

### تحميل ملف موجود
1. انقر على زر "رفع ملف" 🔼
2. اختر ملف HTML من جهازك
3. سيتم تحميل الملف وعرض محتواه

### حفظ عملك
- انقر على "تحميل" ⬇️ لحفظ الملف على جهازك
- أو استخدم `Ctrl+S` (أو `Cmd+S` على Mac)
- المحتوى يُحفظ تلقائياً في متصفحك

### حذف المحتوى
- انقر على "حذف" 🗑️ لمسح كل المحتوى

## 🛠️ التكنولوجيا المستخدمة

- **HTML5** - للهيكل الأساسي
- **CSS3** - للتصميم العصري والمتجاوب
- **JavaScript (Vanilla)** - للوظائف التفاعلية
- **LocalStorage** - للحفظ التلقائي

## 📋 المتطلبات

- متصفح حديث (Chrome, Firefox, Safari, Edge)
- لا توجد متطلبات إضافية!

## 🔒 الأمان

- جميع العمليات تتم على جهازك محلياً
- لا يتم إرسال البيانات إلى خادم خارجي
- استخدام `sandbox` في iframe للحماية من البرامج الضارة
